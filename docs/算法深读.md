## 1. 负荷计算（`load.py`）

### 1.1 系数来源：用途指标表（`design_defaults.py`）

`PURPOSE_DEFAULTS` 是"每个房间用途对应的设计指标"，代码读取后**覆盖** `RoomInput` 的默认值：

| 用途 | 冷指标 W/m² | 热指标 W/m² | 新风 m³/h·人 | 照明 W/m² | 设备 W/m² |
| --- | --- | --- | --- | --- | --- |
| office 办公 | 115 | 75 | 30 | 10 | 15 |
| meeting 会议 | 150 | 85 | 35 | 12 | 10 |
| mall 商场 | 180 | 90 | 25 | 18 | 20 |
| hotel 酒店 | 125 | 80 | 30 | 8 | 10 |
| classroom 教室 | 140 | 85 | 30 | 11 | 8 |

> 这些是行业常用"单位面积冷指标"经验值（GB 50189 / 民用建筑暖通设计手册的工程估算区间）。
> 密度越高的空间（商场>教室>办公）冷指标越大。

`ORIENTATION_SOLAR_W_M2`：朝向太阳辐射强度（W/m² 窗面积）：
`north 60 / south 140 / east 110 / west 160 / internal 0`（西晒最重、南向次之、内区无）。

### 1.2 冷负荷分项公式（量纲推导）

设房间面积 `A`、人数 `n`、新风量 `G = n × 新风指标`、夏季温差 `ΔTs = T外夏 - T内夏`：

```
① 面积指标冷负荷   Q_area = A × 冷指标 / 1000            [W→kW]
② 人员冷负荷       Q_people = n × 0.12                    [人×kW/人]
③ 照明冷负荷       Q_light = A × 照明指标 / 1000
④ 设备冷负荷       Q_equip = A × 设备指标 / 1000
⑤ 新风显热冷负荷   Q_fa = ρ·cp·G·ΔTs / 3600               [kJ/h ÷ 3600 = kW]
⑥ 新风潜热冷负荷   Q_lat = max(RH外 - RH内, 0) × G × 0.00072
⑦ 太阳辐射冷负荷   Q_solar = (A × 外围护系数 × 窗墙比) × 太阳指标 × 0.55 / 1000
```

- **⑤ 的量纲核对**：ρ[kg/m³]×cp[kJ/kg·K]×G[m³/h]×ΔT[K] = kJ/h；÷3600 → kW。✓
- **⑦ 的系数 0.55** = 外窗"太阳得热系数(SHGC)+玻璃遮阳系数"的工程折减，把直射辐射换算成进室得热。
- **潜热系数 0.00072 kW/(m³/h·RH)**：由"室内外含湿量差随相对湿度差变化"标定的经验系数，用于简化新风除湿负荷。

最终 `冷负荷 = ①+②+③+④+⑤+⑥+⑦`。

### 1.3 热负荷分项公式

设冬季温差 `ΔTw = T内冬 - T外冬`、外围护面积 `A_围 = A × 外围护系数`：

```
⑧ 围护传热热负荷  Q_env = U × A_围 × ΔTw / 1000        [W→kW]，即稳态传热 Q=U·A·ΔT
⑨ 新风显热热负荷  Q_fa_heat = ρ·cp·G·ΔTw / 3600
⑩ 面积指标热负荷  Q_area_heat = A × 热指标 / 1000
热负荷 = max(⑩, ⑧ + ⑨)        # 取面积指标法与围护+新风法的较大值
```

### 1.4 汇总与调整

```
adjusted_cooling = Σ房间冷负荷 × simultaneity_factor × safety_factor
                  = 总冷负荷 × 0.9 × 1.1      （默认值）
```

- **simultaneity_factor（同时使用系数 0.9）**：不是所有房间同一时刻满载，取 0.9 折减。
- **safety_factor（安全系数 1.1）**：覆盖设计误差与极端工况，放大 1.1。
- 净效果：0.9×1.1 ≈ **0.99**，两者近似抵消，但保留了"先折减后放大"的工程叙事。

### 1.5 样例（手算）

房间：`office`，面积 120 m²，18 人，朝南，ΔTs=9℃、ΔTw=25℃、RH外0.65/RH内0.55、
U=1.2、外围护系数 1.4、窗墙比 0.25、新风 30 m³/h·人。

```
G = 18×30 = 540 m³/h
① = 120×115/1000           = 13.800
② = 18×0.12                =  2.160
③ = 120×10/1000            =  1.200
④ = 120×15/1000            =  1.800
⑤ = 1.2×1.005×540×9/3600  =  1.629
⑥ = 0.10×540×0.00072       =  0.039
⑦ = 120×1.4×0.25×140×0.55/1000 = 3.234   （窗面积42 m²）
冷负荷 = 13.8+2.16+1.2+1.8+1.629+0.039+3.234 = 23.862 kW

⑧ = 1.2×(120×1.4)×25/1000 = 5.040
⑨ = 1.2×1.005×540×25/3600 = 4.525
⑩ = 120×75/1000            = 9.000
热负荷 = max(9.0, 5.04+4.525=9.565) = 9.565 kW

adjusted_cooling = 23.862×0.9×1.1 = 23.62 kW
```

（与 `sample_system.json` 中 office_1 房间同参数。）

## 2. 水量计算（`water.py`）

### 2.1 核心系数 0.86 的推导

流量公式 `Q[m³/h] = 0.86 × P[kW] / ΔT[K]`。推导：

```
P = ρ·c·Q·ΔT                     （热平衡，P 取 kW= kJ/s）
Q = P / (ρ·c·ΔT)
代入 ρ=1000 kg/m³, c≈4.186 kJ/kg·K：
Q[m³/s] = P / (1000×4.186×ΔT)
换算为 m³/h：Q = P×3600 / (4186×ΔT) = P×0.86/ΔT
```

> **0.86 ≈ 3600/4186** 就是把"比热折算+秒/小时换算"打包成一个工程系数。这就是暖通行业
> "1 kW 负荷 5℃ 温差约需 0.172 m³/h 冷冻水"这一口诀的由来。

### 2.2 选管与阻力公式

```
流量 Q[m³/s] = Q[m³/h]/3600
所需截面积 A_need = Q / v_target
标准管表（DN15~300）中选第一个 A ≥ A_need 的管子
实际流速 v = Q / A
动压头     P_dyn = ρ·v²/2                       [Pa]
沿程阻力   ΔPf = f·(L/D)·P_dyn                   [f=0.025]
局部阻力   ΔPl = ζ·P_dyn                         [ζ 默认 6.0]
总阻力     ΔP = ΔPf + ΔPl                       [Pa]
水泵扬程   H = ΔP/(ρ·g) × 1.1                   [m 水柱，×1.1=10%裕量]
```

- **f·(L/D)** 是 Darcy-Weisbach 公式的摩阻系数形式；`0.025` 对应钢管湍流过渡区的典型值。
- **ζ=6.0** 是单管段"阀门+弯头+三通"局部阻力系数合计的工程估算。
- **/1000 与 /1000**：管径 mm→m、面积换算已内联。

### 2.3 流速校核（`rules.json`）

| 系统 | 下限 m/s | 上限 m/s | 超限 issue |
| --- | --- | --- | --- |
| 冷冻水 | 0.6 | 2.5 | `WATER_VELOCITY_LOW/HIGH` |
| 冷却水 | 0.8 | 3.0 | 同上 |
| 热水 | 0.5 | 2.0 | 同上 |

下限是"防沉积/防气堵"，上限是"防噪声与磨损"。

### 2.4 样例

冷负荷 100 kW、ΔT=5℃、目标流速 1.5 m/s、管长 30 m、ζ=6：

```
Q = 0.86×100/5 = 17.2 m³/h = 0.004778 m³/s
A_need = 0.004778/1.5 = 0.003185 m²
查表：DN80 内径80mm → A=π×0.08²/4=0.005027 ≥ 0.003185 ✓  选 DN80
v = 0.004778/0.005027 = 0.950 m/s（在冷冻水 0.6~2.5 区间内 ✓）
P_dyn = 1000×0.950²/2 = 451.7 Pa
ΔPf = 0.025×(30/0.08)×451.7 = 4234.7 Pa
ΔPl = 6×451.7 = 2710.3 Pa
ΔP = 6945 Pa ≈ 6.95 kPa
H = 6945/(1000×9.80665)×1.1 = 0.779 m
```

## 3. 风量/风管计算（`air.py`）

### 3.1 送风量公式

```
Q[m³/h] = P[kW]×1000×3600 / (ρ·cp·ΔT)
        = P×1000×3600/(1.2×1005×ΔT)
```

- 把冷负荷换算成"送风显热平衡所需风量"，ΔT 默认 10℃（送/回风温差，供风16℃/回风26℃典型值）。
- 1005 J/kg·K 与负荷模块 1.005 kJ/kg·K 是同一物理量，单位写法不同。

### 3.2 选管与校核

- 矩形管：标准表 `(160×120)…(2000×1000)`，选第一个面积够的；
- 圆管：`STANDARD_ROUND_DUCTS_MM` 100~1600，同理；
- 实际风速 `v = Q/A`；
- 校核：>8 m/s → `AIR_VELOCITY_HIGH`（噪声大），<2 m/s → `AIR_VELOCITY_LOW`（主风管浪费）；
- 超过标准表最大 → `DUCT_OVERSIZE_REQUIRED`。

### 3.3 样例

冷负荷 100 kW、ΔT=10℃、目标流速 6 m/s：

```
Q = 100×1000×3600/(1.2×1005×10) = 360,000,000/12,060 ≈ 29,851 m³/h
Q = 8.29 m³/s；A_need = 8.29/6 = 1.382 m²
矩形表第一个≥1.382：1600×1000 = 1.6 m² ✓
v = 8.29/1.6 = 5.18 m/s（2~8 区间 ✓）
```

## 4. 水力管网（`hydraulic_network.py`）

### 4.1 分系统流量分配

```
冷冻水流量 Q_chw = 0.86×冷负荷/5.0     （ΔT=5℃，7/12℃供回）
冷却水流量 Q_cw  = Q_chw × 1.2          （冷凝热≈冷负荷+压缩机功率≈1.2×冷负荷）
热水流量   Q_hw  = 0.86×热负荷/10.0     （ΔT=10℃供热典型）
```

> **×1.2 的来源**：冷却塔排走的热量 = 冷负荷 + 压缩机耗功。冷水机 COP≈5 时
> 压缩机功≈冷负荷×0.2，所以冷凝热≈1.2 倍冷负荷。

### 4.2 路径与最不利环路

```
对每个水系统枚举网络路径（network_paths.py）
路径压降 = Σ 该路径上各管段压降 + 连通设备压降
路径扬程 = 路径压降/(ρ·g) × 1.1
最不利路径 = 压降最大者
所需泵扬程 = max(各路径扬程)
```

- 设备压降来源：目录里 `water_pressure_drop_kpa`（×1000→Pa，按台数累加）和 `pressure_drop_pa`；
- 设备局部系数：目录 `local_resistance_coefficient` × 台数（terminal/cold_source/water_accessory）。

### 4.3 水泵校核

```
流量余量 = Σ泵额定流量 / 需流量      （rules: 1.0 ~ 1.25）
扬程余量 = max泵额定扬程 / 需扬程     （rules: 1.05 ~ 1.3）
余量不足 → PUMP_FLOW_LOW / PUMP_HEAD_LOW；过大 → *_HIGH
无泵数据  → PUMP_FLOW_UNKNOWN / PUMP_HEAD_UNKNOWN（error）
```

### 4.4 水力平衡

```
不平衡率 = (最大路径压降 - 最小路径压降) / 最大路径压降
> 15% → HYDRAULIC_IMBALANCE（需加平衡阀或调管径）
```

## 5. 风网管网（`air_network.py`）

### 5.1 当量直径与压降

```
矩形风管当量直径 D_h = 2·w·h/(w+h)        （水力直径，等速/等阻折算用）
ΔP = f×(L/D_h)×P_dyn + ζ×P_dyn + 设备压降
   f = 0.02（空气），ζ = 管段局部系数 + 连通设备局部系数
```

### 5.2 风机校核与平衡

```
所需风机压力 = max(各风路路径压降)
风量余量 = Σ末端设备风量 / 需风量
静压余量 = 可用静压 / 需压力（可用静压取 design_options.fan_static_pressure_pa 或目录外静压）
静压余量 < 1.05 → FAN_PRESSURE_LOW；无静压数据 → FAN_PRESSURE_UNKNOWN（info）
路径压降偏差 >15% → AIR_BALANCING_REQUIRED
末端总风量 < 需风量 → TERMINAL_AIRFLOW_LOW
```

## 6. 稳态仿真（`simulation.py`）

```
容量比 r = Σ冷源容量 / 设计冷负荷
r ≥ 1 → 室温 26℃；r < 1 → 室温 = 26 + (1-r)×8℃（每缺 10% 容量约升温 0.8℃）
冷机功率 = 冷负荷 / COP          （COP 取目录 cop 加权，默认 4.5）
泵/风机功率 = 目录 power_kw 求和
供/回水 7/12℃、送风 16℃
```

## 7. 能耗仿真（`energy.py`）

### 7.1 逐时负荷剖面

```
季节系数 S = 0.45 + 0.55×(0.5 + 0.5·sin(2π·pos - π/2))    （pos=小时位置，>24h 才启用）
占用系数 O = 占用时段内按"中间峰"折线，非占用时段固定 0.28
负荷系数 L = max(0.08, S×O)
部分负荷比 PLR = 负荷/冷源容量（封顶 1.2）
```

- 季节系数把一年负荷拟合成正弦波，范围 0.45~1.0（冬季谷、夏季峰）；
- 0.08 下限模拟"空调待机/基础负荷"。

### 7.2 能耗模型

```
冷机能耗 = 负荷 / COP
泵能耗   = 泵功率 × (0.72/泵效率) × (0.35 + 0.65·PLR²)      # 离心泵"相似定律"：功率∽流量²
风机能耗 = 风机功率 × (0.30 + 0.70·PLR³)                     # 风机"相似定律"：功率∽流量³
累计 kWh 求和；费用 = 累计 × electricity_price_per_kwh（默认0.85 元/kWh）
```

> **PLR² / PLR³ 的物理来源**：泵/风机转速下降时，相似定律给出 `P2/P1 = (n2/n1)²`（泵）和
> `(n2/n1)³`（风机），而流量近似正比转速，故功率随部分负荷比呈二次/三次下降。
> `0.35/0.65`、`0.30/0.70` 是"额定效率段 + 变工况段"的拆分经验系数。

## 8. 关键注意点

1. **所有 `_round(x, 3)` 保留 3 位小数**，跨模块汇总时先各自 round 再求和，会有微小舍入差。
2. **流量优先级**：`topology.pipe_flow_m3_h`（拓扑分配） > 显式 `flow_m3_h` > `base_flow/管数`。
3. **目录型号优先**：设备容量/流量/扬程/COP 一律先查 `equipment_catalog.json`，查不到才回落
   到 `RoomInput`/请求覆盖值或 `DEFAULT_DEVICE_CAPACITY_KW`。
4. **去重**：所有 issue 在返回前按 `(level, code, message, target)` 去重，避免跨模块重复报。
5. 本模块全部是工程估算；如需施工级精确，替换为逐级动态模拟或第三方软件。
