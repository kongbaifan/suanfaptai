# 文件结构说明

面向学生课堂使用的中央空调教学软件后端（Python/FastAPI + Vue 3）的完整目录结构逐层解释。
本目录负责算法、接口、仿真和教学工作台数据服务；它采用工程估算和教学级模型，不替代正式
施工图设计、厂家选型或第三方审图计算。

## 根目录

```
suanfaptaizhichi/

```

## `app/` — FastAPI 后端

### 顶层模块（入口与业务编排）

```
app/
├── main.py                    # 【入口】FastAPI 应用实例 + 全部 REST/WS 路由注册
├── schemas.py                 # 【契约】所有接口的 Pydantic 请求/响应模型
├── realtime.py                # 实时仿真：session 生命周期、控制指令、WS 广播
├── samples.py                 # 内置示例系统（complete / multi_floor / 四层FCU等）
├── reporting.py               # 评估报告生成（汇总负荷/水力/风网/建议）
├── equipment_selection.py     # 教学设备选型：从项目派生需求，评价目录型号
├── equipment_knowledge.py     # 设备知识库接口（11 类设备原理，只读）
├── teaching_scenarios.py      # 教学方案对比逻辑
├── building.py                # 建筑/楼层/房间的节点归属模型
├── room_bindings.py           # 房间→末端绑定：把 RoomInput.device_ids 倒置成 device→rooms
├── project_validation.py      # 项目 JSON 格式校验入口
├── release.py                 # 版本元数据、资源路径发现、启动自检诊断
├── release_manifest.json      # 发布清单（版本、schema 版本号、资源列表）
└── diagnostics.py             # 服务自诊断：环境 + 资源检查 + 数据规模 + 实时会话
```

### `app/calculators/` — 静态工程计算

```
calculators/
├── load.py                    # 冷热负荷计算（围护、人员、照明、新风等）
├── air.py                     # 风量计算（换气次数、负荷反算风量）
├── water.py                   # 水量计算（负荷/温差反算水流量）
├── air_network.py             # 风系统管网：管段风速、压降、风机压力参考
├── air_tree.py                # 树状风网求解器
├── hydraulic_network.py       # 多支路水力：分系统流量分配、管段阻力、最不利环路
├── topology.py                # 拓扑分析：孤立节点、混接、水环路开闭检查
├── network_paths.py           # 管网路径搜索工具
├── energy.py                  # 能耗仿真（按运行工况积分）
└── simulation.py              # 稳态仿真的入口封装（调用 simcore）
```

### `app/simcore/` — 统一仿真核心（实时 + 稳态共用）

```
simcore/
├── session.py                 # 【核心 61KB】仿真 session：逐 Tick 推进、状态演化
├── devices.py                 # 设备物理模型：冷机/热泵/泵/冷却塔/末端特性
├── hydronics.py               # 水系统闭环：支路分流、供回水温混合、守恒
├── pipes.py                   # 实时管段读数：末端水量沿拓扑累加，反算流速与压降
├── controls.py                # 教学化自动调节：按室温偏差调台数/转速/阀位
├── rated.py                   # 从设备目录读取额定值，标记降级来源
├── project.py                 # 项目数据 → 仿真内部表示的装配
├── room.py                    # 房间热容积分模型（温度动态）
├── steady.py                  # 稳态求解：动态核在设计工况下的不动点
└── weather.py                 # 室外气象参数
```

### `app/steady_solver/` — 稳态端口图求解器

### `app/unity_catalog/` — 设备角色与几何词汇表

名字仍带 unity 前缀，但已不是桥接代码：`DeviceRole` 是 `simcore` 与
`steady_solver` 共用的设备角色枚举，端口数量与介质判定都依赖它。

```
unity_catalog/
├── roles.py                   # DeviceRole 枚举与角色/求解行为映射
├── catalog.py                 # 按 (DeviceID, ModelID) 查设备规格
├── geometry.py                # 从型号名解析 DN / 矩形尺寸 / 铜管外径
├── quality_report.py          # 目录质量报告
└── examples.py                # 用法示例
```

`catalog.py` 读 `Assets/StreamingAssets/SoftwareSerializationData/Json/DeviceLibrary.json`
（427 条）。该文件缺失时 `steady_solver/port_graph.py` 会按设备类型名推断端口，
仿真不受影响，只损失端口精度。

## `tests/` — pytest 测试（约 29 个文件）

按被测对象命名，分几类：

- **仿真核心**：`test_simcore_session.py`、`test_simcore_hydronics.py`、`test_simcore_monotonic.py`、`test_simcore_rated.py`、`test_realtime.py`、`test_realtime_pipes.py`、`test_realtime_runtime_isolation.py`
- **求解器**：`test_steady_solver.py`、`test_hardy_cross.py`、`test_manifold_solver.py`、`test_air_network_tree_solver.py`
- **业务功能**：`test_equipment_selection.py`、`test_heat_pump_selection.py`、`test_teaching_scenarios.py`、`test_equipment_knowledge.py`、`test_catalog_management.py`
- **样例验证**：`test_four_floor_fcu_fresh_air_sample.py`、`test_multi_zone_all_air_sample.py`
- **不变性**：`test_room_order_invariance.py`（房间数组顺序不得影响任何计算结果）
- **设备角色词汇表**：`test_unity_catalog.py`
- **API 集成**：`test_api.py`、`test_api_integration.py`、`test_diagnostics_api.py`

## `save/` — 运行时数据

用户在工作台保存的项目数据目录（运行时生成）。

---

**整体数据流**：`web/`（Vue 前端）→ `app/main.py`（路由）→ `schemas.py`（校验）→ `calculators/`（静态计算）或 `simcore/`（动态仿真）→ `data/`（参数库/存储）→ 响应回前端。
