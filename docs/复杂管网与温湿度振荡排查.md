# 复杂管网与温湿度振荡排查

> 2026-10-09：本轮排查的出水温、控制振荡和复杂连接计算已收尾，当前实现与验收见
> [连接驱动动态仿真](连接驱动动态仿真.md)。下文保留 2026-10-08 的改前实验记录。
> 旁通、串联泵及有向环状替代通路现已纳入完整通路约束分配；仍使用明确标识的教学
> 压差上界模型，`pressure_balance_solved=false`，不宣称厂家曲线工作点或一般网状压力平衡。

本轮按用户要求聚焦复杂管网支持和温湿度持续振荡。厂家曲线精度不作为后续工作的前置要求，现有教学模型及参数来源说明继续保留。

以下为当前版本的代码检查与进程内对照实验，未修改运行算法。冻结控制量和取消取整仅用于定位，不是已交付的控制策略。

## 1. 复杂管网：能力缺口与现有误判

最小项目为一个空气源热泵、循环泵和两个并联风机盘管；额定末端流量各 1.892 m³/h。对相同项目逐项改变连接后测得：

| 接法 | 结果 |
| --- | --- |
| 普通并联末端 | 总流量 3.784 m³/h，正常 |
| 增加并联泵 | 两个末端仍正常；普通并联泵已有支持 |
| 增加供回水旁通，`pipe_type=bypass` | 整个组件标为 `unsupported`，流量为 0 |
| 相同旁通改成 `pipe_type=unknown` | 总流量仍为 3.784；旁通没有参与分流，组件标为 `modeled`，issues 为空 |
| 两台泵串联 | 流量为 0，误报 `SIM_WATER_PATH_INCOMPLETE` 和 `disconnected` |
| 两条末端支路间增加交叉连接 | 一条末端维持通流，另一条因多路径被排除；组件仍显示部分可计算 |

问题集中在 `app/simcore/runtime_network.py` 的 `_water_paths`：显式旁通标记会整体禁算；通路围绕末端枚举，无法计算绕过末端的循环；每次查路又排除其他水泵，因此串联泵被当成缺路。

当前不能通过简单删除 `bypass` 限制实现旁通支持。至少必须增加：

- 根据连接结构识别旁通，避免只依赖 `pipe_type`。
- 完整网络上的流量与压力约束，纳入每台泵的压升和限流。
- 旁通流量及回水混合：泵流量 = 末端流量 + 旁通流量。
- 串联泵的同流量、压升叠加；系统总流量不能把串联泵流量重复相加。
- 多路径与回路耦合的求解、残差和失败处理。

现有 Hardy-Cross 可复用阻力、回路及守恒相关代码，但不是已完成的运行时泵网求解器。`PumpCurve` / `model.pumps` 虽有定义，当前回路修正仅累加管道压降，没有调用泵压升；节点压力和泵工作点输出也尚未接入。

可沿用教学级泵 / 阀参数开展扩展，主要工作在网络求解及热量传递，而非厂家数据准备。优先修正漏判和错误分类，再扩展真实支持范围。

## 2. 振荡：当前数据与因果对照

现有 `test_humidity_control_settles_instead_of_limit_cycling` 没有冻结室外天气。其原条件下，观察窗口内室外温度跨度达 7.42℃，因此“所有状态最终静止”不是合理的动态天气验收条件。

但冻结天气后，振荡仍然存在。对照条件：四层样例、目标 24℃ / 55%、室外湿度 70%、固定 14 点天气、300 s/步，预热 3000 步，再观察 600 步。以下为一层办公室的单步最大变化：

| 实验 | 温度变化 | 实际 RH 变化 |
| --- | ---: | ---: |
| 原自动控制、固定天气 | 0.03978 K | 0.66989 pp |
| 仅固定冷机供水目标为 7℃ | 0.04424 K | 0.06565 pp |
| 仅固定各末端组台数为 3 台 | 0.00335 K | 0.26486 pp |
| 仅使自动阀位 / 转速 / 温度设定连续，不改变切台数逻辑 | 0.03915 K | 0.64143 pp |
| 固定末端台数 + 连续自动控制 | 小于 1e-8 K | 小于 1e-8 pp |

最后一项中六个房间均在观测精度内稳定。完全固定所有控制量的独立实验也得到稳定状态，但部分房间会过冷，因此不能直接以“锁死控制”交付。

原控制中还观察到：

- 一层末端组在 2 台 / 3 台间反复切换，单次风量跳变约 1203.6 m³/h，冷量跳变约 5.06 kW。
- 台数固定后，阀位仍在相邻整数百分数间跳动；自动控制复用了手动输入的步长取整。
- 除湿触发切换会使冷机供水目标反复变化，进一步扰动新风机组潜热处理。
- 将时间步从 300 s 缩短到 60 s，原控制的办公室湿度单步变化降到 0.093 pp，仍未消除问题。

证据支持：当前四层样例的主要触发点是台数分级与连续调节没有协调，以及自动控制的步长取整；供水目标切换进一步放大扰动。现有物理模型在固定控制下可以稳定，不应先通过更换设备或修改盘管能力掩盖这个控制问题。

后续修复应：

1. 将末端台数选择与阀位 / 风机调节协调，切台数时避免整组输出突跳，并明确迟滞与保持策略。
2. 自动连续控制与手动指令的输入步长分开；保留手动控制、范围限制和变化速率约束。
3. 除湿供水目标按服务回路处理，并增加适当的切换记忆，避免阈值附近反复切换。
4. 固定天气验收温度与湿度收敛；动态天气验收跟随、守恒和波动边界。当前稳态判据没有单独校验湿度，也应补齐。

建议顺序：先防止复杂接法漏算 / 误报，再修复控制振荡，随后扩展旁通、串联泵与环网求解。原温湿度验收标准和人工控制语义应保留。
