# 前端适配接口清单

面向 Vue 前端（`web/`）适配的接口清单，基于 `app/main.py` 当前 58 个路由（57 HTTP + 1 WebSocket）逐个核对整理。
仓库内实现的客户端为 Vue 工作台；Unity 等外部客户端可使用同一套 REST / WebSocket 接口接入，无需在客户端计算暖通数值。
（注意：设备角色语汇 `app/unity_catalog/` 与同步层 `app/data/unity_sync.py` 仍在使用，
前者被 15+ 处模块引用，后者对应活路由 `POST /catalog/equipment/sync-unity`。）

> 初版生成日期：2026-09-08，于 2026-10 按 `app/main.py` 与 `web/src` 重新逐个核对。
> 接口级字段语义详见 [接口文档.md](接口文档.md)，本清单不重复展开字段表，
> 只给适配所需的路径、模型、错误码与消费方。

## 1. 总览

动态网络已接入 `RealtimeState.network`，由 `RuntimeNetworkPanel.vue` 展示水管、风管、独立回路和定位诊断。控制确认使用 `session_id`、`control_revision`、`applied_control_revision`，客户端拒收旧会话和旧 tick；设备控制同时展示已接受值与本步有效值。房间编辑新增供 / 回风口绑定，风机盘管支持显式直吹 / 风管式声明。完整字段见 [连接驱动动态仿真](连接驱动动态仿真.md)。

| 分档 | 数量 | 说明 |
| --- | --- | --- |
| 主体：已接入 | 34（含 WS） | 前端当前实际调用，含 store action → 页面映射 |
| 主体：待接入 | 6 | 建议接入的产品缺口，分高/中/低优先级 |
| 附录：暂不接入 | 17 | 聚合冗余 / 管理调试 / 边缘，前端不写适配代码 |
| 静态入口 | 1 | `GET /` 托管 Vue 构建产物（浏览器直达，非 API 适配对象） |
| 合计 | 58 | 57 HTTP + 1 WS，与 main.py 路由数一致 |

**通用约定**：

- Base URL：开发期 Vite 代理（见 `web/vite.config.ts`），部署期同源；所有业务路径前缀 `/api/v1`
- 无鉴权；JSON 请求/响应
- 错误响应 `detail` 有三种形态（`web/src/api/client.ts` 的解析逻辑已对齐）：
  1. 字符串（404/422 常规错误）
  2. `{code, message}` 对象（409，如仿真运行中禁止编辑项目）
  3. Issue 数组（422，房间绑定/配置校验，每项含 `code/message/severity`）
- WebSocket 断线由前端自动重连（指数退避，最多 6 次，上限 15s，`web/src/stores/realtime.ts`）
- 评估计算耗时较长的接口（system/evaluate、steady-state）无异步任务机制，同步阻塞返回，前端需 loading 态

| 事件 | 语义 | 前端处理（已实现） |

| `POST /api/v1/realtime/update` | **外部状态注入通道，无消费者**。仿真循环自动推送，Vue 不用；历史遗留，可选下线候选 |
| `POST /api/v1/project/validate` | 服务端项目校验。前端有本地 `validateProjectDraft`，保存时后端亦兜底校验 |

**边缘（2 个）**——保留无害：

| 方法+路径 | 说明 |
| --- | --- |
| `GET /api/v1/rules` | 设计规则限值只读，无消费者（前端只在注释里提过 water_velocity 限值） |
| `GET /health` | 极轻量健康检查，被 diagnostics 覆盖 |
